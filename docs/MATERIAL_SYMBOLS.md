# Material Symbols

Demo图标来自Google Material Symbols Outlined（2026-11-03获取），按需包含bluetooth、check、delete、refresh、settings、arrow_back。

来源：https://github.com/google/material-design-icons/tree/master/symbols/android

保留原始矢量路径；去掉Android主题tint引用，改用Compose Icon的颜色；填充改成等值白色常量；返回箭头保留RTL自动镜像。

Apache-2.0许可全文见MATERIAL_SYMBOLS_LICENSE.txt。资源分别位于两个Demo的composeResources/drawable，未增加图标库依赖。
